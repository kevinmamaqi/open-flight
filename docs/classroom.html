Classroom flight guide

Can the same flyer land closer to a target when you change the way you release it? Fold a plane or make a paper butterfly and find out together.

Open the free Starter 3 book

Plan your copies

The Starter 3 book includes two folded-body butterflies and a whole-sheet plane. Print one set of model sheets and one shared set of instructions per team.

What to print PDF pages Copies

Copy counts cover the Starter 3 PDF. Print one copy of this classroom guide separately for the facilitator.

Run a fair test

For each K2 butterfly use 120 g/m² paper and two 33 mm clips. Share scissors, a ruler and an empty ballpoint pen for scoring. Each airplane uses one sheet.

  1. Build one model together. An adult helps with tight cuts and small clips. Let younger learners point to a crease or predict a landing spot with a finger.
  2. Mark a launch line and a target in a clear lane. Take turns flying, marking the first point of contact and recording the result. Use the same flyer and launcher in both sets.
  3. Try five level launches. Change only the release angle for the next five, pointing the nose a little down. Keep release height and push similar. Record misses too. Did the marks move closer to the target?

From phone to printer

Open the Starter 3 book and download the PDF. Use Share to print if your device offers it, or save the PDF to Files or Downloads. For a print shop, send the PDF and the copy instructions together.

Choose matching paper, Actual size or 100%, one PDF page per sheet and single-sided printing. Turn off Fit to page. Print page 2 first and measure the 50 mm line with a ruler before printing the rest.
